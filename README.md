# Responsive Education Website

A modern and fully responsive education website built using HTML and CSS. This project features a clean and user-friendly interface with multiple sections, including courses, categories, FAQs, testimonials, and a responsive navigation menu.

## Features

- Responsive design for all screen sizes
- Modern and clean UI
- Hero section
- Popular courses section
- Categories section
- FAQ accordion
- Testimonials section
- Footer with social media links
- Smooth hover effects and animations

## Purpose

This project was created to improve my front-end development skills by practicing responsive layouts, modern UI design, and semantic HTML structure.
